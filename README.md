# Ralph dos Reis Torres

Estudante de **Ciência da Computação na UFG**, apaixonado por desenvolvimento de software e interessado em **Inteligência Artificial, Engenharia de Software e Desenvolvimento Web**. Tenho experiência com desenvolvimento Front-end, Back-end, APIs e UI/UX Design, buscando construir soluções funcionais e com boa experiência para o usuário.

Participei do desenvolvimento de um **chatbot de orientação estratégica para startups**, atuando no desenvolvimento da interface, integração de APIs, estruturação da lógica da aplicação e refinamento da base de conhecimento. Também participei da modelagem e documentação da solução utilizando **BPMN, C4 Model e Diagramas de Requisitos**.
